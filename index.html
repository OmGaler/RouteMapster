About RouteMapster

What this is

RouteMapster is a unified London bus route explorer, built to explore coverage, operators, and service patterns quickly without drowning in raw data.

Data sources

  • TfL Bus Open Data - route geometry
  • TfL Unified API - StopPoint + timetable data
  • LondonBusRoutes.net - garage allocations
  • postcodes.io - postcode enrichment
  • OpenStreetMap - basemap tiles

Notes

Not affiliated with TfL.
